# Marcura — Scope 3 Carbon Intelligence Platform (UI Prototype)

A UI-first, enterprise-grade dashboard prototype built with Next.js 15, TypeScript, Tailwind CSS v4,
shadcn/ui-style primitives, Recharts, Framer Motion, and React Leaflet. All data is synthetic and
generated locally — there is no backend.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

To produce a production build:
```bash
npm run build
npm run start
```

## Regenerating the synthetic dataset

All JSON fixtures live in `src/data/`. They're generated by `scripts/gen_data.py` (seeded, deterministic):

```bash
python3 scripts/gen_data.py
```

Edit the counts at the top of that script to scale the dataset up or down (default: 100 companies,
500 suppliers, 300 customers, 250 warehouses, 150 ports, 300 vessels, 800 trucks, 5,000 shipments,
24 months of history + 12-month forecast).

## Notes

- Dark mode is the default; toggle via the sun/moon icon in the top bar or in Settings.
- Live vessel/truck tracking pages animate synthetic positions client-side (no real telemetry).
- The AI Carbon Copilot uses simple keyword-matched canned responses grounded in the synthetic
  dataset — it's a UI demonstration, not a live LLM integration.
- Map tiles are loaded from CARTO's free basemap CDN (no API key required); swap in Mapbox GL JS
  and a token in `src/components/map/` if you'd prefer Mapbox-specific styling/vector tiles.
- This is UI-first: there is no backend, database, or auth. All "Download", "Connect", and
  settings toggles are illustrative only.
